# cc.brandguidelines

Guía de estilo de Cachito de Cielo: color, tipografía, jerarquía, espacio y forma,
componentes, movimiento, voz y tokens del sitio público.

**Ver en línea:** https://cachito-de-cielo.github.io/cc.brandguidelines/

## Qué hay aquí

- `index.html`: la guía completa en una sola página autocontenida (CSS, JS e imágenes
  incrustadas; solo carga Google Fonts).
- `.nojekyll`: hace que GitHub Pages sirva el archivo tal cual, sin pasar por Jekyll.

Se publica con GitHub Pages desde la rama `main`, carpeta raíz.

## Fuente de verdad

Los tokens se definen en el proyecto **"Cachito de Cielo Design System"** en Claude Design.
Esta página es una exportación de ese proyecto: los cambios se hacen allá y aquí solo se
reemplaza `index.html`. No edites los valores a mano en este repo.
